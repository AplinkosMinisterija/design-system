React 19 and React Router 8 upgrade — breaking change for v2.0.0

Upgrade to React 19.0.0, react-dom 19.0.0, and react-router 8.3.0. Consumers must upgrade their own React installations to 19.x and React Router to 8.x. All component APIs remain unchanged; only internal dependencies and TypeScript configuration have been updated for React 19 compatibility.
