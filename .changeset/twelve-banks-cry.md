React 19 and React Router 7 upgrade — breaking change for v2.0.0

Upgrade to React 19.2.8, react-dom 19.2.8, react-router 7.1.5, and react-router-dom 7.1.5. Consumers must upgrade their own React installations to 19.x and React Router to 7.x. All component APIs remain unchanged; only internal dependencies and TypeScript configuration have been updated for React 19 compatibility.
